# Amortisation Calculator Privacy Policy

This repository contains the privacy policy page for the **Amortisation Calculator** application.

## About the Project

The Amortisation Calculator is a financial calculation application designed to help users estimate loan or asset-finance repayments and view amortisation information.

This repository hosts the application's privacy policy as a standalone HTML page.

## Repository Contents

* `privacy-policy.html` — Privacy Policy page for the Amortisation Calculator.

## Purpose

The privacy policy explains how information may be handled when users interact with the Amortisation Calculator application. It is provided to meet transparency and privacy requirements for users and app distribution platforms.
